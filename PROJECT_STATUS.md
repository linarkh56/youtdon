# Статус проекта

Готово: TypeScript/Electron scaffold, версионированные SQLite migrations v1/v2 с атомарной записью, уникальностью платежа и счётчиком попыток playback, строгий YouTube URL parser, целочисленный тариф, backup/download и проверяемое restore из UI, безопасное восстановление прерванного playing-заказа, FIFO queue с автоматическим продвижением, queue clear с сохранением истории, refund transition, backend playback timer с pause/resume, одна автоматическая retry при ошибке YouTube с последующей передачей модератору, controls pause/resume/skip/stop/retry/remove, отдельное окно YouTube IFrame Player API с обработкой API-ошибок, read-only loopback overlay с WebSocket и reconnect, mock-провайдер, loopback API с preload IPC-токеном, строгая Zod-валидация DTO, moderation transitions, history endpoint/UI, authenticated version metadata, safe error journal и diagnostics endpoint, изменяемая конфигурация тарифа, graceful shutdown, панель очереди/модерации с escaping, русскоязычный renderer без дублированной инициализации, unit/integration-тесты и Windows CI-конфигурация.

Не проверено: реальные DonationAlerts OAuth/Centrifugo и DonatePay API, полноценный YouTube IFrame/OBS lifecycle, Windows Credential Manager и установка на чистой Windows. Локальный install smoke подтвердил создание `%APPDATA%\\youtdon\\youtdon.sqlite` и `youtdon.log`, а silent uninstall удалил установленный exe; проверка на чистой Windows 10/11 остаётся ручным gate. Последний installer `release/YouTube Donation Player Setup 0.1.0.exe` собран из `df1316c`, SHA-256 `7C61A09B2117547E6BA4959D8A2F630AE23F57A20F22910306B44485F494B469`; проверка подписи PowerShell показала `NotSigned`, поэтому release signing требует отдельный сертификат и шаг. Electron обновлён до 44.7.2, electron-builder до 26.15.3 и Vitest до 5.0.4. Production audit чистый; полный audit оставляет 8 moderate dev-toolchain vulnerabilities через electron-builder, исправление требует breaking downgrade/upgrade review.

Следующий этап перед коммерческим выпуском: ручная установка/удаление на чистой Windows 10/11, полный YouTube IFrame/OBS acceptance, проверка реального crash/restart сценария, подпись installer сертификатом и отдельное подключение DonationAlerts/DonatePay после получения credentials. Инструкции провайдеров находятся в `docs/INTEGRATION_DONATIONALERTS_RU.md` и `docs/INTEGRATION_DONATEPAY_RU.md`; фактические проверки перечислены в `docs/TEST_REPORT_RU.md`. До этого приложение предназначено для mock-потока и тестирования, а не для приёма реальных платежей.
