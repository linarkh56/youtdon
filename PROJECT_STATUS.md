# Статус проекта

Готово: TypeScript/Electron scaffold, версионированные SQLite migrations v1/v2 с атомарной записью, уникальностью платежа и счётчиком попыток playback, строгий YouTube URL parser, целочисленный тариф, backup/download и проверяемое restore из UI, безопасное восстановление прерванного playing-заказа, FIFO queue с автоматическим продвижением, backend playback timer с pause/resume, одна автоматическая retry при ошибке YouTube с последующей передачей модератору, controls pause/resume/skip/stop/retry/remove, отдельное окно YouTube IFrame Player API с обработкой API-ошибок, read-only loopback overlay с WebSocket и reconnect, mock-провайдер, loopback API с preload IPC-токеном, строгая Zod-валидация DTO, moderation transitions, history endpoint/UI, изменяемая конфигурация тарифа, diagnostics endpoint, graceful shutdown, панель очереди/модерации с escaping, русскоязычный renderer без дублированной инициализации, unit/integration-тесты и Windows CI-конфигурация.

Не проверено: реальные DonationAlerts OAuth/Centrifugo и DonatePay API, полноценный YouTube IFrame lifecycle, Windows Credential Manager и установка на чистой Windows. Упакованный executable локально прожил smoke-запуск 6 секунд без Node/npm; установка/удаление на чистой Windows остаются ручным gate. Локально `dist:installer` создал `release/YouTube Donation Player Setup 0.1.0.exe` с иконкой приложения; installer не подписан сертификатом, release signing требует отдельный сертификат и шаг. Electron обновлён до 44.7.2, electron-builder до 26.15.3 и Vitest до 5.0.4. Production audit чистый; полный audit оставляет 8 moderate dev-toolchain vulnerabilities через electron-builder, исправление требует breaking downgrade/upgrade review.

Следующий этап перед коммерческим выпуском: ручная установка/удаление на чистой Windows 10/11, полный YouTube IFrame/OBS acceptance, проверка реального crash/restart сценария, подпись installer сертификатом и отдельное подключение DonationAlerts/DonatePay после получения credentials. До этого приложение предназначено для mock-потока и тестирования, а не для приёма реальных платежей.
