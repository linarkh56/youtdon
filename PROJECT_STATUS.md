# Статус проекта

Готово: TypeScript/Electron scaffold, строгий YouTube URL parser, целочисленный тариф, SQLite schema с уникальностью платежа, FIFO queue и проверяемые переходы статусов, mock-провайдер, loopback API, русскоязычный тестовый renderer, unit-тесты и NSIS-конфигурация.

Не проверено: реальные DonationAlerts OAuth/Centrifugo и DonatePay API, полноценный YouTube IFrame lifecycle, OBS WebSocket overlay, Windows Credential Manager, installer на целевой Windows.

Следующий этап: player controller, WebSocket overlay, защищённое хранилище credentials, миграции, интеграционные тесты и ручной acceptance checklist.
