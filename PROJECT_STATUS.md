# Статус проекта

Готово: TypeScript/Electron scaffold, версионированная SQLite migration v1 с атомарной записью и уникальностью платежа, строгий YouTube URL parser, целочисленный тариф, backup/download и проверяемое restore из UI, безопасное восстановление прерванного playing-заказа, FIFO queue с автоматическим продвижением, backend playback timer с pause/resume, controls pause/resume/skip/stop/retry/remove, отдельное окно YouTube IFrame Player API, read-only loopback overlay с WebSocket и reconnect, mock-провайдер, loopback API с preload IPC-токеном, строгая Zod-валидация DTO, moderation transitions, history endpoint/UI, изменяемая конфигурация тарифа, diagnostics endpoint, graceful shutdown, панель очереди/модерации с escaping, русскоязычный renderer, unit/integration-тесты и Windows CI-конфигурация.

Не проверено: реальные DonationAlerts OAuth/Centrifugo и DonatePay API, полноценный YouTube IFrame lifecycle, Windows Credential Manager и установка на чистой Windows. Локально `dist:installer` создал `release/YouTube Donation Player Setup 0.1.0.exe`; installer не подписан, release signing требует сертификат и отдельный шаг. Electron обновлён до 44.7.2, electron-builder до 26.15.3 и Vitest до 5.0.4. Production audit чистый; полный audit оставляет 7 moderate dev-toolchain vulnerabilities.

Следующий этап: player controller, WebSocket overlay, защищённое хранилище credentials, миграции, интеграционные тесты и ручной acceptance checklist.
