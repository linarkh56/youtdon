# Статус проекта

Готово: TypeScript/Electron scaffold, версионированные SQLite migrations v1/v2 с атомарной записью, уникальностью платежа и счётчиком попыток playback, строгий YouTube URL parser, целочисленный тариф, backup/download и проверяемое restore из UI, безопасное восстановление прерванного playing-заказа, FIFO queue с автоматическим продвижением, queue clear с сохранением истории, refund transition, backend playback timer с pause/resume, одна автоматическая retry при ошибке YouTube с последующей передачей модератору, controls pause/resume/skip/stop/retry/remove, отдельное настраиваемое окно YouTube IFrame Player API с сохранением размера и режимом «поверх других окон», mock-провайдер, loopback API с preload IPC-токеном, строгая Zod-валидация DTO, moderation transitions, history endpoint/UI, authenticated version metadata, safe error journal и diagnostics endpoint, изменяемая конфигурация тарифа, graceful shutdown, панель очереди/модерации с escaping, русскоязычный renderer без дублированной инициализации, unit/integration-тесты и Windows CI-конфигурация.

Не проверено: реальные DonationAlerts OAuth/Centrifugo и DonatePay API, полноценный YouTube IFrame/window-capture lifecycle, Windows Credential Manager и установка на чистой Windows. Локальный install smoke подтвердил создание `%APPDATA%\\youtdon\\youtdon.sqlite` и `youtdon.log`, а silent uninstall удалил установленный exe; проверка на чистой Windows 10/11 остаётся ручным gate. Последний installer `release/YouTube Donation Player Setup 0.1.0.exe` собран из `893f3a6`, SHA-256 `0B65666EAE1E0C01E2F7CBCA4F53BF6F088ADBCBF242084F96750495E66E1531`; подпись не используется для локального тестирования, PowerShell показывает `NotSigned`. Electron обновлён до 44.7.2, electron-builder до 26.15.3 и Vitest до 5.0.4. Production audit чистый; полный audit оставляет 8 moderate dev-toolchain vulnerabilities через electron-builder, исправление требует breaking downgrade/upgrade review.

Следующий этап перед коммерческим выпуском: ручная установка/удаление на чистой Windows 10/11, полный YouTube IFrame и захват окна в OBS, проверка реального crash/restart сценария и отдельное подключение DonationAlerts/DonatePay после прохождения авторизации владельцем. Подпись installer не требуется для локального тестирования, но Windows SmartScreen может показать предупреждение. Инструкции провайдеров находятся в `docs/INTEGRATION_DONATIONALERTS_RU.md` и `docs/INTEGRATION_DONATEPAY_RU.md`; фактические проверки перечислены в `docs/TEST_REPORT_RU.md`. До этого приложение предназначено для mock-потока и тестирования, а не для приёма реальных платежей.
