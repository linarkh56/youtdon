# Инструкция

Запустите `npm start`, используйте тестовый донат и вставьте поддерживаемую ссылку YouTube. Для DonationAlerts потребуется зарегистрировать OAuth-приложение и подтвердить scopes по официальной документации. Для DonatePay потребуется API-ключ. Технический отказ ролика не является возвратом платежа.
