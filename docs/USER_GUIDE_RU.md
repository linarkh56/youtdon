# Инструкция

Запустите приложение, используйте тестовый донат и вставьте поддерживаемую ссылку YouTube. Видео открывается в отдельном окне YouTube Donation Player. Размер окна и режим «поверх других окон» настраиваются в панели управления и сохраняются локально. В OBS выберите захват окна (Window Capture) и укажите окно YouTube Donation Player. Для DonationAlerts потребуется пройти официальную авторизацию в приложении после реализации адаптера. Для DonatePay потребуется официальная авторизация/ключ. Технический отказ ролика не является возвратом платежа.
