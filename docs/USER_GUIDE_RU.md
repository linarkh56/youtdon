# Инструкция

Запустите `npm start`, используйте тестовый донат и вставьте поддерживаемую ссылку YouTube. Для OBS добавьте Browser Source с адресом `http://127.0.0.1:<порт>/overlay.html`; overlay получает только read-only состояние через WebSocket и автоматически переподключается. Для DonationAlerts потребуется зарегистрировать OAuth-приложение и подтвердить scopes по официальной документации. Для DonatePay потребуется API-ключ. Технический отказ ролика не является возвратом платежа.
