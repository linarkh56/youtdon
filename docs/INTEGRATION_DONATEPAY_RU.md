# Будущее подключение DonatePay

Сейчас DonatePay не подключён: API credentials отсутствуют, реальные события не принимались. Приложение работает только через `MockAdapter`; фиктивные DonatePay endpoints не создаются.

После получения доступа владелец должен:

1. Получить API-ключ и разрешения по официальной документации DonatePay.
2. Сохранить ключ в защищённом хранилище Windows, не помещая его в репозиторий, installer, URL или diagnostics export.
3. Реализовать адаптер `PaymentAdapter` через официальный API или webhook-механизм, проверяя подлинность события и нормализуя id, сумму в копейках, RUB, сообщение и timestamp.
4. Обеспечить дедупликацию по `(provider, providerDonationId)`, повторное подключение после сетевой ошибки и безопасное удаление/ротацию ключа.
5. Провести ручной тестовый сценарий, проверку повторной доставки и security review перед включением реального провайдера.

До выполнения этих шагов статус остаётся `требуется настройка/не проверено`, а финансовые операции запрещены.
