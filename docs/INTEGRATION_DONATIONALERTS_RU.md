# Будущее подключение DonationAlerts

Сейчас DonationAlerts не подключён: credentials отсутствуют, реальные события не принимались. Приложение работает только через `MockAdapter` и не должно использовать этот документ как инструкцию для обхода официальной авторизации.

После получения доступа владелец должен:

1. Создать официальное OAuth-приложение DonationAlerts и проверить redirect URI и scopes по актуальной документации провайдера.
2. Сохранить client id, client secret и refresh token в защищённом хранилище Windows, не добавляя их в репозиторий, installer, URL или diagnostics export.
3. Реализовать адаптер `PaymentAdapter` с официальным API/stream-событиями, нормализацией `providerDonationId`, валюты, суммы в копейках, сообщения и времени получения.
4. Обеспечить дедупликацию по `(provider, providerDonationId)`, повторное подключение после сетевой ошибки и явное логирование без секретов.
5. Провести ручной sandbox/тестовый сценарий и security review перед включением реального провайдера.

До выполнения этих шагов статус остаётся `требуется настройка/не проверено`, а финансовые операции запрещены.
