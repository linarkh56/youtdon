# Политика обработки данных (черновик)

Приложение хранит локально заказы, технические статусы, настройки тарифа и логи, необходимые для работы очереди. В текущем mock-only режиме данные не отправляются в DonationAlerts или DonatePay. Loopback API доступен только на локальном компьютере.

Перед коммерческим выпуском владелец продукта должен проверить требования законодательства, сроки хранения, удаление и резервное копирование данных, а также условия реальных платёжных провайдеров. Этот документ не является юридической консультацией.
