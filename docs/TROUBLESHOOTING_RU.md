# Устранение неполадок

- Приложение не стартует: удалите только временный `data` каталог после создания backup и запустите снова; проверьте системный журнал.
- Тестовый заказ отклонён: проверьте HTTPS-ссылку YouTube, ID видео, сумму не ниже минимума и валюту RUB.
- Overlay пустой: проверьте, что адрес использует `127.0.0.1`, сервер приложения запущен, а Browser Source переподключён.
- После сбоя заказ получил `interrupted`: это безопасное поведение, приложение не воспроизводит оплаченный заказ повторно автоматически.
- Для диагностики экспортируйте JSON-отчёт из интерфейса. Не отправляйте базу или логи третьим лицам без удаления чувствительных данных.
