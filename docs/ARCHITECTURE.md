# Архитектура

Electron main запускает окно и loopback HTTP API. `domain` содержит чистые правила URL, денег и очереди. `persistence` использует версионированные SQLite migrations, транзакции и уникальность `(provider, providerDonationId)`; база сериализуется через `sql.js` в файл userData, WAL-режим не заявляется. `integrations` изолирует провайдеры через `PaymentAdapter`. `observability` хранит ограниченный безопасный журнал в `%APPDATA%` и отдаёт его только authenticated diagnostics endpoint. Renderer не принимает финансовых решений; управляющий token доступен только через минимальный preload IPC. Overlay получает HttpOnly loopback-сессию при открытии страницы и подключается к read-only WebSocket без секретов в URL.
