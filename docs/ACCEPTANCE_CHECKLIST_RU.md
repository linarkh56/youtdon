# Ручной acceptance checklist

- [ ] Установить Windows installer на чистую Windows 10/11 без Node.js.
- [ ] Запустить приложение и убедиться, что база создаётся в `%APPDATA%`.
- [ ] Добавить mock-донат со ссылкой `https://youtu.be/dQw4w9WgXcQ`.
- [ ] Убедиться, что тестовый заказ визуально отмечен и появляется один раз.
- [ ] Проверить повторную отправку того же `providerDonationId`.
- [ ] Проверить паузу, продолжение, остановку и переход к следующему заказу.
- [ ] Проверить controls `Пауза`, `Продолжить`, `Пропустить`, `Остановить` и повторную попытку прерванного заказа через API/модерацию.
- [ ] Перезапустить приложение и проверить восстановление очереди.
- [ ] Добавить `http://127.0.0.1:<порт>/overlay.html` в OBS Browser Source.
- [ ] Проверить переподключение overlay после перезапуска OBS.
- [ ] Проверить отсутствие доступа к API без локального токена.
- [ ] Проверить экспорт диагностики без секретов.
- [ ] Зафиксировать, что DonationAlerts и DonatePay не подключены без credentials.
